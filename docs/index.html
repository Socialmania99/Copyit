Features

Everything you copied, one search away

Copyit does one job: it remembers what you copy and gives it back in the shape you need.

Save from anywhere

  • Right-click selected text, a link, an image or a page address and choose Save to Copyit.
  • Paste with Ctrl+V in the dashboard, or press Save clipboard.
  • Drag and drop files, images, videos, text, .json and .csv.

Find in a second

  • Search text, tags (#reading-list) and domains.
  • Filter by type with live counts, including Multimedia.
  • Enter copies the first result. Alt+1–9 copies the Nth clip.

Folders, tags, stars and pins

  • Make your own folders and move clips into them.
  • Add tags; Copyit cleans and de-duplicates them.
  • Pin what you need today, star what you keep.

10 formats, rich previews

  • JSON pretty-printed, CSV as a table, Markdown rendered, code with a language label.
  • HTML, CSS, rich text, SVG, images and data URIs.
  • Long clips scroll with the mouse wheel, and on hover.

Copy as…

  • JSON: formatted or minified. CSV: tab-separated, Markdown table, JSON array.
  • Rich text with formatting, plain text, or HTML source.
  • Links as Markdown or HTML anchors. Code as a fenced block. Images as PNG or data URI.

Images, video and links

  • Save images, SVG and videos (up to 25 MB) with a thumbnail.
  • The Preview button opens a small window: full-size image, video player, PDF, or the real page for websites and YouTube.
  • Open in a new tab, download, or copy from the viewer.

Scan to open on a phone

  • Every short clip gets its own QR code.
  • Works for text and links up to 5 KB. A link opens in the phone's browser. Text shows on screen.
  • Works offline. No server, no account.

Sensitive clips stay blurred

  • Passwords, API keys, private keys, JWTs and card numbers are detected and blurred until you press Reveal.
  • Leave them out of backups with one switch.

Import, export, back up

  • Settings → Import & export: choose several files at once.
  • Export a full JSON backup (with media), CSV, text or Markdown.
  • Retention rules, a history limit and a Clear all clips button with Undo.

How it works

Three ways in, one vault

Copyit never watches your clipboard. Something is saved only when you ask.

Press Save clipboard

Open Copyit and press Save clipboard. It reads the clipboard once and keeps text, rich text, HTML and images together.

Right-click and save

Select text, or right-click a link, an image or the page, and choose the Save to Copyit entry.

Paste or drop

In the dashboard, press Ctrl+V or drag in files, images, videos and backups.

Scan to open

Short clips on any phone

Every clip has a share button. It shows a QR code you scan with the camera of any smartphone. It is built for short clips only, up to 5 KB.

  • A different QR code for every clip.
  • Links open in the phone's browser. The QR holds the address itself, so the phone needs internet only to load the page.
  • Text opens on the phone's screen. The QR holds the text itself, so no internet is needed. Longer text, up to 5 KB, becomes numbered QR codes. Scan them in order.
  • Fully offline. The QR is made on your computer. Nothing is uploaded, and nothing expires.
  • Short clips only. Images, videos, files and anything over 5 KB are too big for a QR code. Use Copy or Export for those.
Privacy

Your clips stay in your browser

Copyit has no account, no analytics and no server. It asks Chrome for six permissions and no website access, so it cannot read the pages you visit.

storageSaves your clips and settings in Chrome's storage on this computer.
unlimitedStorageLets images and videos be kept without hitting the default size cap.
contextMenusAdds the right-click entries for selected text, links, images and pages.
clipboardReadReads the clipboard only when you press Save clipboard. It is never read in the background.
clipboardWritePuts a clip back on your clipboard when you press Copy.
downloadsSaves files you ask for, such as a backup or a video.
Install guide

Install Copyit in about five minutes

Copyit is not on the Chrome Web Store yet. You install it by hand with Chrome's Developer mode. It is safe, it takes a few clicks, and the steps below are written for first-timers.

What you need. A computer with Google Chrome (Windows, Mac, Linux or Chromebook). The Chrome mobile app cannot install extensions. Edge and Brave use the same steps, with edge://extensions or brave://extensions instead.

  1. Download the file from GitHub

    Open the GitHub link below. Under Assets, click copyit-v1.0.zip. It goes to your Downloads folder.

    Open the GitHub release

  2. Unzip it

    A zip file is a folder squeezed into one file. Chrome cannot load it that way, so open it up first.

    WindowsRight-click the zip, choose Extract All…, then Extract.
    MacDouble-click the zip. A folder appears next to it.
    Linux / ChromebookRight-click the zip and choose Extract here, or double-click it and extract.
    What you should see: a folder named copyit. Open it once. Inside are files like manifest.json, popup.html and icons. If you see only another copyit folder, open that one: it is the folder with manifest.json inside.

  3. Put the folder somewhere it can stay

    Chrome keeps using the files in that folder every time it starts. Move the copyit folder to a place you will not clean up, such as Documents. Do not leave it in Downloads, and do not delete it later, or Copyit stops working.

  4. Open Chrome's extensions page

    Click the address bar at the top of Chrome, type the address below, and press Enter.

    chrome://extensions

    Or click the three-dot menu (⋮) at the top right, then Extensions, then Manage Extensions. Some browsers block links to chrome:// pages, so copy the address and paste it into the address bar yourself.

  5. Turn on Developer mode

    At the top right of the extensions page, find the switch labeled Developer mode and click it so it turns blue or dark.

    What you should see: three new buttons appear at the top left: Load unpacked, Pack extension and Update.

  6. Click “Load unpacked”

    Press Load unpacked. A window opens so you can pick a folder from your computer.

  7. Choose the copyit folder

    Go to where you put the folder (for example Documents), click the copyit folder once, and press Select Folder (Windows/Linux) or Select (Mac). Pick the folder that has manifest.json directly inside it, not the zip and not a folder above it.

    What you should see: a new Copyit card on the extensions page, with the version 1.0.0 and its switch turned on.

  8. Pin Copyit to the toolbar

    Click the puzzle-piece icon at the top right of Chrome, find Copyit, and click the pin icon next to it. Now the Copyit icon is always one click away. You can also open it with Ctrl+Shift+Y (Command+Shift+Y on Mac).

  9. Try it

    On any web page, select a few words, right-click them, and choose Save selected text to Copyit. Click the Copyit icon: your clip is there. Press Copy to put it back on your clipboard. Open the heart or the Settings link for options. That is the whole setup.

If something goes wrong

“Manifest file is missing or unreadable”You picked the wrong folder. Select the folder that has manifest.json directly inside it. Do not pick the zip, and do not pick a folder that only contains another copyit folder.
I cannot see “Load unpacked”Developer mode is off. Turn it on with the switch at the top right of the extensions page.
Copyit disappeared or shows an errorThe folder was moved, renamed or deleted. Put it back where it was, or remove Copyit and load the folder again from its new place.
Chrome shows a developer-mode extension warning when it startsChrome shows this for every extension installed outside the Web Store. Dismiss it. Copyit keeps working.
The shortcut does nothingAnother extension may use the same keys. Open chrome://extensions/shortcuts and set your own for Copyit.
I do not see the iconClick the puzzle-piece icon and pin Copyit, as in step 8.

Updating later

Back up first. Chrome ties an extension you load by hand to its folder location. Open Copyit → Settings → Import & export → JSON backup and keep the file. Then replace the files inside the same folder with the new version, open the extensions page, and click the circular reload arrow on the Copyit card. If you load it from a different folder, Chrome treats it as a new extension. Your clips are not copied across, but you can bring them back with Import files and your backup.

Is this safe? Developer mode is Chrome's normal way to run extensions that are not in the store. Copyit is plain JavaScript and HTML that you can read in the folder, and it does not ask for access to websites. Only install files from a source you trust, and keep Developer mode on only if you want to.

FAQ

Questions people ask first

Is Copyit on the Chrome Web Store?

Not yet. For now you install it by hand with Developer mode, as the install guide above shows. Once it is in the store, installing will be a single click.

Does Copyit watch everything I copy?

No. It reads the clipboard only when you press Save clipboard or save something yourself. It does not run in the background and it cannot see the pages you visit.

Where are my clips stored?

In Chrome's storage on your computer. Nothing is sent anywhere. QR codes are made on your device too.

How do the QR codes work?

Press the share button on a short clip. A QR code appears. For a link, the QR holds the address and your phone opens it in the browser. For text, the QR holds the text itself, so any camera app shows it, even with no internet. Text up to 5 KB works. Longer text is split into numbered QR codes you scan in order.

Can I share an image, a video or a long document?

No. A QR code can only carry a few kilobytes, so Scan to open is for short text and links up to 5 KB. For anything bigger, use Copy, or export a backup from Settings and move the file yourself.

Why does Preview open a real window for YouTube and websites?

YouTube and most websites refuse to be shown inside another page. Copyit opens the real page in a small window instead. Images, videos, vectors and PDFs open in Copyit's own viewer.

Can I move my clips to another computer?

Yes. Export a JSON backup from Settings → Import & export, install Copyit on the other computer, and choose the backup with Import files. Images and videos come along.

How do I remove Copyit?

Open chrome://extensions and press Remove on the Copyit card. This deletes your saved clips too, so export a backup first if you want to keep them.
